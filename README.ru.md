# tgexport

[English](README.md) · **Русский**

> Основная документация — на английском в [README.md](README.md). Здесь — краткая
> версия на русском.

`tgexport` превращает экспорт чата из Telegram Desktop (`result.json`) в
удобный формат: обычный текст, автономную HTML-страницу, Markdown, CSV или
упрощённый JSON.

```text
$ tgexport result.json
✓ Алиса → /Users/me/Алиса.txt (163 messages)

$ head -3 Алиса.txt
2026-10-22 22:09:09 Алиса: и что это значит
2026-10-22 22:20:51 Боб: [GIF]
2026-10-22 22:28:49 Боб: ты любишь воду?
```

- Личные чаты, группы, каналы и **полный экспорт аккаунта**.
- Один бинарник без зависимостей: macOS / Linux / Windows, amd64 / arm64.
- Форматы: **txt** (по умолчанию), **html**, **md**, **csv**, **json**.
- Фильтры по датам и авторам, отключение служебных сообщений и заглушек медиа.
- HTML — один офлайн-файл: тёмная/светлая тема, ответы, реакции, пересланные
  сообщения, форматирование, блоки кода, поиск.

## Установка

**macOS / Linux**

```sh
curl -fsSL https://raw.githubusercontent.com/antalkon/tgexport/main/scripts/install.sh | sh
```

Бинарник ставится в `~/.local/bin` (или туда, где `tgexport` уже лежит). Если
папки нет в `PATH`, установщик допишет её в профиль оболочки (`~/.zshrc` и т.п.)
— перезапустите терминал. Параметры:

```sh
curl -fsSL https://raw.githubusercontent.com/antalkon/tgexport/main/scripts/install.sh \
  | sh -s -- --version v0.1.0 --dir /usr/local/bin --no-modify-path
```

**Windows (PowerShell)**

```powershell
irm https://raw.githubusercontent.com/antalkon/tgexport/main/scripts/install.ps1 | iex
```

Ставится в `%LOCALAPPDATA%\Programs\tgexport` и добавляется в пользовательский
`PATH`; права администратора не нужны. После установки откройте новый терминал.

**Через Go** (1.23+)

```sh
go install github.com/antalkon/tgexport/cmd/tgexport@latest
```

**Вручную** — скачайте архив со страницы
[Releases](https://github.com/antalkon/tgexport/releases/latest), сверьте с
`checksums.txt`, распакуйте и положите `tgexport` в папку из `PATH`.

Оба скрипта проверяют SHA-256 скачанного архива перед установкой.

## Обновление

Запустите ту же команду установки ещё раз. Скрипт сравнит установленную версию
с последним релизом и либо обновит бинарник на месте, либо напишет
`already installed — nothing to do`. Флаг `--force` (`-Force` в Windows) —
переустановить принудительно. Текущая версия: `tgexport version`.

## Удаление

**macOS / Linux**

```sh
curl -fsSL https://raw.githubusercontent.com/antalkon/tgexport/main/scripts/uninstall.sh | sh
```

**Windows (PowerShell)**

```powershell
irm https://raw.githubusercontent.com/antalkon/tgexport/main/scripts/uninstall.ps1 | iex
```

**Go**: `rm "$(go env GOPATH)/bin/tgexport"`.

## Как получить JSON из Telegram

1. Откройте **Telegram Desktop** (в мобильных приложениях экспорта нет).
2. Чат → меню **⋮** → **Экспорт истории чата**.
3. Снимите галочки с ненужных медиа, выберите **Формат: машиночитаемый JSON** → **Экспортировать**.
4. Получится папка `ChatExport_2026-10-31/` с файлом `result.json`.

Полный экспорт аккаунта (**Настройки → Продвинутые настройки → Экспорт данных
из Telegram**, формат JSON) тоже поддерживается, см. `--chat`.

## Использование

```text
tgexport [флаги] <result.json | папка-экспорта>
tgexport stats <result.json | папка-экспорта>
tgexport version
```

- На вход — путь к `result.json` **или** к папке экспорта.
- По умолчанию результат сохраняется **в текущую папку** (откуда запущена
  команда) как `<имя чата>.<расширение>`, например `Алиса.txt`. Существующий
  файл перезаписывается. Недопустимые символы (`/ \ : * ? " < > |`) заменяются на `_`.
- Флаги можно писать и до, и после имени файла.
- Коды выхода: `0` — успех, `1` — ошибка (нет файла, битый JSON…), `2` — неверные аргументы.

Формат txt по умолчанию — одно сообщение на строку: `дата время пользователь: текст`.
Многострочные сообщения продолжаются строками с отступом в 4 пробела.
Нужен вид `дата:время:пользователь сообщение`? Используйте шаблон:

```sh
tgexport result.json --layout "{date}:{time}:{user} {text}"
# 2026-10-22:22:09:09:Алиса и что это значит
```

## Форматы

| Формат | Флаг | Описание |
| --- | --- | --- |
| `txt` | *(по умолчанию)* | Одна строка на сообщение, удобно для `grep`. |
| `html` | `--html` или `-f html` | Офлайн-страница в стиле чата: даты, цитаты ответов (клик — переход к сообщению), реакции, «изменено», пересылки, ссылки, код, спойлеры, поиск, тёмная тема. |
| `md` | `-f md` | Markdown, раздел на каждый день, сохраняет жирный/курсив/код/ссылки. |
| `csv` | `-f csv` | Таблица для Excel / Google Sheets / pandas. |
| `json` | `-f json` | Плоский стабильный JSON, проще исходного формата Telegram. |

Медиа отображается заглушками: `[photo]`, `[sticker 🤔]`, `[voice message 0:02]`,
`[GIF]`, `[file report.pdf]`, `[poll Обед?]`; пересылки — `[forwarded from Канал]`;
служебные сообщения — `* pinned a message`, `* added Боб`.

## Флаги

| Флаг | По умолчанию | Описание |
| --- | --- | --- |
| `-f, --format` | `txt` | `txt`, `html`, `md`, `csv`, `json` |
| `--html` | | То же, что `--format html` |
| `-o, --output` | текущая папка | Файл, папка (существующая или с `/` на конце) или `-` для stdout |
| `--from` | | Сообщения начиная с даты: `ГГГГ-ММ-ДД` или `"ГГГГ-ММ-ДД ЧЧ:ММ"` |
| `--to` | | Сообщения до даты включительно (дата без времени — весь день) |
| `-u, --user` | | Только сообщения автора (имя или ID вида `user123`); можно повторять или через запятую |
| `--no-service` | | Без служебных сообщений (вступления, закрепы, звонки) |
| `--no-media` | | Без заглушек медиа; пустые после этого сообщения пропускаются |
| `--chat` | | Для полного экспорта аккаунта: только чат с этим именем или ID |
| `--layout` | `{date} {time} {user}: {text}` | Шаблон строки txt. Плейсхолдеры: `{date}` `{time}` `{user}` `{user_id}` `{id}` `{text}` |
| `--date-format` | `2006-01-02` | Формат даты в нотации Go, например `02.01.2006` |
| `--time-format` | `15:04:05` | Формат времени в нотации Go, например `15:04` |
| `--me` | | В HTML показывать сообщения этого автора справа, как свои |
| `-q, --quiet` | | Не печатать итоговую строку `✓ чат → файл` |
| `-v, --version` | | Версия |
| `-h, --help` | | Справка |

## Примеры

```sh
# папка экспорта → HTML в текущей папке, мои сообщения справа
tgexport ~/Downloads/"Telegram Desktop"/ChatExport_2026-10-31 --html --me "Алексей"

# только 1–15 октября, только Боб, без служебных
tgexport result.json --from 2026-10-01 --to 2026-10-15 -u Боб --no-service

# привычные даты: 22.10.2026 22:09 Алиса: …
tgexport result.json --date-format 02.01.2006 --time-format 15:04

# в stdout и дальше по конвейеру
tgexport result.json -o - | grep -i дедлайн

# статистика по чату
tgexport stats result.json

# полный экспорт аккаунта: все чаты в ./exports/ или один
tgexport ~/Downloads/DataExport_2026-10-31 -f md -o exports/
tgexport ~/Downloads/DataExport_2026-10-31 --chat "Алиса"
```

## Вопросы

**Фото и файлы попадают в HTML?** Нет — tgexport работает только с
`result.json` и показывает вложения заглушками. HTML полностью автономный и
ничего не загружает из сети.

**Время сдвинуто.** Telegram пишет время в часовом поясе компьютера, на котором
делали экспорт, без указания пояса. tgexport выводит его как есть.

**В Windows после установки «команда не найдена».** Откройте новый терминал —
изменения `PATH` применяются только к новым сессиям.

**Данные куда-то отправляются?** Нет, утилита работает полностью офлайн.

## Разработка

```sh
make test      # тесты с -race
make lint      # gofmt, go vet, golangci-lint
make build     # ./bin/tgexport
make golden    # обновить эталонные файлы после намеренного изменения вывода
make snapshot  # локальная сборка всех платформ через GoReleaser
```

Релиз — пуш тега `vX.Y.Z`: GitHub Actions прогоняет тесты, GoReleaser собирает
архивы и `checksums.txt`, затем smoke-тест ставит, повторно запускает и
удаляет релиз на macOS, Linux и Windows. Подробнее — в [CONTRIBUTING.md](CONTRIBUTING.md).
